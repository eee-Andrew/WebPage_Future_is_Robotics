# Product Images

Add product photos (JPG, PNG, or SVG) to this directory. When you create or edit a product in the admin dashboard, set the **Image Path** field to `assets/img/products/<your-file-name>` (omit the leading slash and folder name). The application will automatically prepend the correct base path even if you rename the project folder.

For best results use images that share a similar aspect ratio (e.g., 4:3 or 3:2) so the catalog grid stays consistent. Files committed to this folder are served directly by Apache/PHP.
